# Show knowledge folders by their names on disk

## Why
The Knowledge tree translates the wiki folders to Pages/Sources or 页面/来源 while the files live under pages/sources. The tree should agree with the paths that people and agents use.

## What Changes
Show every folder by its exact filesystem name in every interface language, including pages and sources. Keep the wiki folders first in the tree.

## Capabilities
### Modified Capabilities
- knowledge: a collection tree uses filesystem folder names in every locale.

## Impact
Knowledge tree rendering, its existing acceptance tests, the Knowledge guide in both languages and the Context canvas.
