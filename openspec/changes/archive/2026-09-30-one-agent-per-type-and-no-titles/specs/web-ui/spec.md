## REMOVED Requirements

### Requirement: Show and edit a title on MCP server and skill pages
**Reason**: MCP servers and skills no longer carry a title — each is its fixed name and its description ([resource-framework](../resource-framework/spec.md) "Carry an optional editable title on the kinds that have one").
**Migration**: The MCP server and skill pages show the name; a description is what distinguishes one from another. Migration 0108 clears the titles already set.
