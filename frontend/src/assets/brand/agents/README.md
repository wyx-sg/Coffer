# Agent marks

The Claude Spark and the OpenAI Blossom are under `../`, as their owners supply
them. DeepSeek Harness uses the DeepSeek whale from `../providers/deepseek.svg`.

`cursor`, `opencode` and `antigravity` come unchanged from
[LobeHub Icons](https://github.com/lobehub/lobe-icons)
(`@lobehub/icons-static-svg` 1.95.1, MIT; `antigravity` is its `-color` file).
The marks are trademarks of their owners and are used only to identify each
agent. `cursor` and `opencode` draw in `currentColor`, which an `<img>` renders
black, so the UI inverts them on the dark theme.
