# Provider marks

Anthropic, OpenRouter, Ollama, vLLM and llama.cpp marks are the vendors' own
files. The OpenAI Blossom is under `../`.

The other vendor marks (`gemini`, `deepseek`, `lmstudio`, `xai`, `mistral`,
`groq`, `together`, `fireworks`, `kimi`, `zhipu`, `minimax`, `qwen`,
`siliconflow`, `qianfan`, `hunyuan`, `stepfun`) come unchanged from
[LobeHub Icons](https://github.com/lobehub/lobe-icons)
(`@lobehub/icons-static-svg` 1.95.1, MIT). That set is the one LobeChat and
Cherry Studio use. `qianfan` is the Baidu AI Cloud mark, and `siliconflow` is
SiliconCloud's.

The marks are trademarks of their owners and are used only to identify each
vendor. The monochrome files (`lmstudio`, `xai`, `groq`) draw in
`currentColor`. An `<img>` renders that as black, so the UI inverts them on the
dark theme.
