# coffer open

Open Coffer's web UI in your browser.

```sh
coffer open [OPTIONS] COMMAND [ARGS]...
```

本页与 `coffer open --help` 打印的内容一致。在下面任何命令后加 `--help`，即可在终端里查看它的选项。

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--json` <span class="cli-chip">选项</span> | 开关 |  |  |
| `--no-browser` <span class="cli-chip">选项</span> | 开关 |  | Print the URL instead of launching a browser. |
