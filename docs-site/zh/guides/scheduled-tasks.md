# 定时任务 {#scheduled-tasks}

**定时任务**是 Coffer 在你选的时间自己发给智能体的一段提示词。每次运行都会开一个新会话，和 Claude Code、Codex 自带的自动化一样：早上的汇总、夜里的构建检查、每周的清理。Coffer 只负责定时和记录；一次运行做什么由提示词决定。想把结果发到聊天里、写成汇报，或者用某个技能，在提示词里写清楚就行。

所有任务都在**定时任务**页面（运行 › 定时任务），附带运行记录。

定时任务是[实验性功能](/zh/guides/experimental-features)：先在**设置 → 功能**里打开。关闭期间任何任务都不运行；你的任务和运行记录都会保留。

## 任务包含什么 {#what-a-task-is}

一个任务包含：

- **时间**：每天、每周、每小时、一次、cron 表达式，或者只在你手动运行时。时间默认是这台 Mac 的本地时间，也可以指定**时区**（IANA 名称，例如 `Asia/Singapore`）；被夏令时跳过的时间会在下一个有效时间运行一次。重复任务最多每 15 分钟运行一次。要工作日运行，用 cron 表达式，例如 `0 9 * * 1-5`。
- **提示词**：要智能体做什么。要用某个技能，在提示词里写上它的名字。提示词是任务自己文件夹里的 Markdown 文件 `PROMPT.md`（见[任务文件夹](#the-task-s-folder)）。
- **智能体**：Claude Code 或 Codex。
- **模型**：从智能体的模型列表里选一个，或者用智能体的默认模型。
- **文件夹**：每次运行的工作目录。可以选这台 Mac 上的任何文件夹，比如某个仓库；不选就在任务自己的文件夹里运行。
- **补跑**：默认打开。见 [Mac 休眠时](#when-the-mac-was-asleep)。

任务只保存在这台 Mac 上，不会同步：任务指向这台机器上的智能体和文件夹，两台 Mac 不能都运行它。

## 新建任务 {#create-a-task}

在定时任务页面点**新建任务**。起个名字，写好提示词，选时间，再选智能体和模型；如果运行要在任务自己的文件夹之外干活，再选一个文件夹。**创建任务**保存后，它到下一个时间点就会运行。

也可以让智能体帮你建：它可以像运行其他命令一样运行 `coffer task add`。

```bash
coffer task add --data '{"prompt": "Check last night'"'"'s build",
  "config": {"schedule": {"kind": "daily", "time": "02:00", "timezone": "Asia/Singapore"},
  "agent": "codex", "cwd": "/Users/me/work/site"}}'
coffer task list
```

## 任务文件夹 {#the-task-s-folder}

每个任务都有自己的文件夹 `~/.coffer/content/workspace/scheduled-tasks/<uid>/`（`coffer task show` 里的 `folder`），`PROMPT.md` 始终放在这里。没有另选文件夹的任务也在这里运行，所以提示词用相对路径就能找到里面的文件；点提示词旁边的**在访达中显示**可以打开这个文件夹。

只有 `PROMPT.md` 是必需的，其余是推荐结构，Coffer 不会自动创建，也不检查：

```text
PROMPT.md     提示词
config/       任务要读的配置和输入数据
state/        几次运行之间留着的状态
output/       每次运行的产出，例如 output/2026-11-11.md
scripts/      只给这个任务用的脚本
```

- **`PROMPT.md`**：可以在任务的**概览**页里改，也可以用任何编辑器改，或者让智能体改；下次运行读的是那时的文件。`coffer task prompt <任务> --data '{"prompt": "…"}'` 会替换它。
- **简单还是复杂**：简单的任务就是一段提示词。复杂的任务，把「怎么做」（步骤和脚本）写成一个 [skill](/zh/guides/skills)，它会同步、可复用、在任何聊天里都能调用；提示词只写一行指向它，比如 `Use the release-check skill with config/release.json`。任务文件夹里就只放这个任务自己的数据：`config/`、`state/`、`output/`。

文件怎么命名、是每天一个文件还是持续更新同一个文件，都由提示词决定。这个文件夹是你的：不会同步，删除任务也不会删掉它。

想同时在手机上收到报告，就在提示词里让智能体通过渠道发一句话并附上文件：

```bash
coffer channel notify seatalk --data '{"text": "今天的日报", "files": ["/Users/me/.coffer/content/workspace/scheduled-tasks/<uid>/output/2026-11-11.md"]}'
```

文件是这台 Mac 上的绝对路径，最多十个，跟在文字后面发送。智能体用 `coffer__channel_notify` 工具也能做到。

## 一次运行是什么样的 {#what-a-run-looks-like}

到点时，智能体在一个新会话里收到提示词。晚了的运行会附一句简短说明，写明原定时间，让智能体判断这件事是否还值得做。任务选的文件夹如果已经不存在，这次运行会直接失败，不会启动。Coffer 不会往任何地方发消息：从运行记录里打开那次运行就能看到回复。如果需要智能体通知你，在提示词里写上；它可以用 `coffer__channel_notify` 或 `coffer channel notify` 通过你的渠道给你发消息和文件。

上一次还没跑完时又到点的运行会被跳过并记录。失败的运行不会重试，因为一轮对话可能已经做了一些事；重复任务连续失败三次会被暂停，并出现在概览页的**需要你处理**里，直到你恢复它。一次性任务运行后会被关闭。Coffer 停止时还在跑的运行记为**已停止**，不算失败。

恢复一个暂停的任务，或者修改任务的运行时间，本身都不会触发运行：任务会等到下一个时间点。已暂停、时间已过的一次性任务，要先改一个新时间才能恢复。

## Mac 休眠时 {#when-the-mac-was-asleep}

Mac 休眠或 Coffer 没在运行时什么都不会运行；Coffer 不会唤醒 Mac。恢复后：

- 最近一次错过的运行，只要原定时间在 7 天内，会补跑一次，并说明它原本应在什么时候运行；
- 更早的都会被跳过并记在运行记录里。

所以定在 23:00 的任务如果被 Mac 休眠错过，第二天早上会补跑。晚了这么久还值不值得做，由智能体判断；迟到时该怎么做，可以写在提示词里。

关掉任务的**补跑**，就会跳过所有错过的运行。

## 页面 {#the-page}

列表显示所有任务，最近要运行的在前；每行写着下次运行时间，或者它已暂停、正在失败。

打开一个任务可以看到顶部（**立即运行**、**暂停**或**恢复**、**编辑**，以及 **⋯ › 删除**）和两个标签页：

- **概览**：什么时候运行、下次运行、智能体、模型、文件夹和补跑，下面是提示词，渲染显示，切到**源码**可以看 Markdown；**编辑**会打开编辑器，**保存**写回 `PROMPT.md`。除提示词外的设置用顶部的**编辑**修改。
- **运行记录**：最近 200 次运行，每次一行的表格——开始时间（日期和时刻）、结果（**完成**、**跳过**、**失败**、**已停止**）、由计划、补跑还是你手动启动、用了多久——跳过或失败的运行在下面写着原因。可以搜索，按结果和启动方式筛选，按开始时间或用时排序。

运行记录里每次运行都以链接给出它的会话：点进去会跳到**会话**页面并选中它；要看这次运行做了什么并接着聊，用那一行的按钮在终端里打开。运行记录默认保留 90 天；在设置 › 数据里修改。
