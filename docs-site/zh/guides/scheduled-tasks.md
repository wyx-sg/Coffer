# 定时任务 {#scheduled-tasks}

**定时任务**是 Coffer 自己发起的一轮对话：到了你选的时间，它把提示词发给你某个聊天里的智能体，回复像平常一样发到那里。早间汇总、每周检查、群话题里的提醒；还有智能体说“部署完我再看一下”时，它给自己约好的跟进。渠道上的**每日汇报**也是一个定时任务。

所有任务都在**定时任务**页（运行 › 定时任务），连同运行记录。同一页还以只读方式列出 Coffer 自己的后台工作。

定时任务是[实验功能](/zh/guides/experimental-features)：先在**设置 → 功能**里开启。关闭期间任何任务都不运行，智能体也不能约跟进；已有的任务和运行记录会保留。

## 任务包含什么 {#what-a-task-is}

一个任务包含：

- **时间**：每天、工作日、每周、每小时、一次、cron 表达式，或只在你手动运行时。时间按这台 Mac 的本地时间。重复任务最短 15 分钟一次。
- **聊天**：你已经在用的、和机器人的某个聊天：你的私聊，或机器人已配对的群。任务只在你和机器人用的聊天里运行。
- **提示词**：要问智能体什么。
- **对话**：**每次新对话**每次都开一个新对话，用你选的智能体、模型和目录（或渠道的默认值）；**接着聊天里的对话**把这次运行发进聊天当前的对话，带着之前说过的一切。
- **补跑**：默认开。见 [Mac 休眠时](#when-the-mac-was-asleep)。

任务只保存在这台 Mac 上，从不同步：任务指向这台机器上的聊天、智能体和目录，两台 Mac 也不能各跑一遍。

## 新建任务 {#create-a-task}

在定时任务页点**新建任务**。填名称（留空则按提示词命名），选聊天，选时间，写提示词，再选对话怎么开始。**创建任务**会保存并打开它。

你也可以在聊天里直接跟机器人说：“每个工作日 9 点，列出昨天合并的 PR”。智能体会建好任务并说明建了什么，任务出现在页面上，你可以修改或删除。

在命令行里：

```bash
coffer task chats                          # 任务可以运行的聊天
coffer task add --data '{"config": {"schedule": {"kind": "weekdays", "time": "09:00"},
  "prompt": "List the pull requests merged yesterday",
  "chat": {"channel": "<channel uid>", "chat_id": "<chat id>"}}}'
coffer task list
```

## 一次运行是什么样的 {#what-a-run-looks-like}

到点时，智能体收到提示词，前面有一段只有它看得到的简短说明：这是哪个任务、原定什么时候、是不是迟到、是不是手动启动的。回复发到任务所在的聊天，有话题就发到话题里。

**没事可说也没关系。** 智能体没有可汇报的内容时，回复以 `[SILENT]` 开头，什么都不会发出。写提示词时说清楚什么时候该保持沉默（“只在检查失败时汇报”）。运行失败一定会在聊天里说明。

上一次还在跑时到点的那一次会被跳过并记录。失败的运行不会自动重试，因为一轮对话可能已经做了一些事；重复任务连续失败三次会被暂停，并通知聊天。

## 智能体约好的跟进 {#follow-ups-an-agent-books}

你问的事要过一阵才有结果时（“部署上线了告诉我”），智能体可以在同一个话题里约一次**跟进**：一个一次性任务，回到那段对话、带着上下文，并找当初提问的人。在群里它会 @ 对方。

智能体自己主动约的只能是跟进，而且有限制：

- 5 分钟到 7 天之后；
- 一个话题里最多同时等着 3 个；
- 一次跟进可以再约下一次，最多连续 10 次，且不超过第一次之后 7 天。

群里只能向机器人提问的人（见[群里的其他人](/zh/guides/channels#others-in-the-group)）不能让它安排任何任务。重复任务的运行里不能再建任务。

跟进列在页面的**跟进**下。跟进运行过后就会被移除；它的运行记录保留在 Coffer 里，直到保留期清理。

## 在聊天里查看和取消 {#see-and-cancel-from-the-chat}

在私聊里，`/status` 按时间先后列出这段对话里在等的任务，比如“⏰ 1. 16:00 Check the deploy”，在有按钮的平台上每个任务带一个**取消**按钮。在群里，问机器人（“你在这里安排了什么？”）或者打开页面。

## 每日汇报 {#the-daily-report}

每天一次，给你发一条简短消息，说一个渠道的对话里发生了什么：问了什么、进展到哪、有什么出了问题。在渠道的**概览**里打开：在**每日汇报**下选时间（默认 18:00），点**设置**。它发到你和机器人的私聊。

汇报由智能体根据当天的对话撰写，运行时从智能体自己的会话里读取；Coffer 不保存对话内容。当天没有渠道对话就什么都不发。汇报还会列出当天被跳过或失败的任务，以及明天在等的任务。

汇报就是一个普通任务：在定时任务页可以改它的提示词、暂停或删除。渠道概览上的开关负责暂停和恢复它。

## Mac 休眠时 {#when-the-mac-was-asleep}

Mac 休眠或 Coffer 没在运行时，什么都不会运行；Coffer 不会唤醒 Mac。恢复以后：

- 最近错过的那一次会迟到运行一次，并说明原定时间；
- 一次性任务最多可以迟到它等待时长的一半（至少 15 分钟，至多 2 小时），跟进只有及时才有用；
- 重复任务错过的那一次在当天结束前都还可以补跑；
- 更早的会被跳过，并记进运行记录。

在任务上关掉**补跑**，所有错过的运行都会直接跳过。

## 页面 {#the-page}

- **我的任务**：你建的任务，包括每日汇报。每行写着下次什么时候运行，或者已暂停、连续失败。
- **跟进**：智能体约好的任务。
- **Coffer 内部**：Coffer 自己的后台工作：同步、记忆同步、清理旧记录、让智能体的配置文件保持一致、启动定时任务等，写着每个怎么被唤醒、上次什么时候运行。**显示全部**列出所有 worker。这里什么都不能改：这些设置在各自的页面上。

打开一个任务，可以看到它的标题栏（**立即运行**、**暂停**或**恢复**、**编辑**，以及 **⋯ › 删除**）、它做什么，以及**运行记录**：每一次运行，最新的在前，写着结果（**已回复**、**无事可报**、**已跳过**、**失败**、**已停止**）和原因。用过对话的运行会写出那个对话，标题是个链接：点它会跳到**对话**页，在列表里选中这个对话并在终端中打开，你可以看这次运行做了什么，也可以接着聊下去。运行记录默认保留 90 天，可在设置 › 数据里修改。
