# 定时任务 {#scheduled-tasks}

**定时任务**是 Coffer 在你选的时间自己发给智能体的一段提示词。每次运行都会开一个新会话，和 Claude Code、Codex 自带的自动化一样：早上的汇总、夜里的构建检查、每周的清理。Coffer 只负责定时和记录；一次运行做什么由提示词决定。想把结果发到聊天里、写成汇报，或者用某个技能，在提示词里写清楚就行。

所有任务都在**定时任务**页面（运行 › 定时任务），附带运行记录。

定时任务是[实验性功能](/zh/guides/experimental-features)：先在**设置 → 功能**里打开。关闭期间任何任务都不运行；你的任务和运行记录都会保留。

## 任务包含什么 {#what-a-task-is}

一个任务包含：

- **时间**：每天、每周、每小时、一次、cron 表达式，或者只在你手动运行时。时间默认是这台 Mac 的本地时间，也可以指定**时区**（IANA 名称，例如 `Asia/Singapore`）；被夏令时跳过的时间会在下一个有效时间运行一次。重复任务最多每 15 分钟运行一次。要工作日运行，用 cron 表达式，例如 `0 9 * * 1-5`。
- **提示词**：要智能体做什么。要用某个技能，在提示词里写上它的名字。
- **智能体**：Claude Code 或 Codex。
- **模型**：从智能体的模型列表里选一个，或者用智能体的默认模型。
- **目录**：会话在哪个目录打开；留空就是主目录。
- **补跑**：默认打开。见 [Mac 休眠时](#when-the-mac-was-asleep)。

任务只保存在这台 Mac 上，不会同步：任务指向这台机器上的智能体和目录，两台 Mac 不能都运行它。

## 新建任务 {#create-a-task}

在定时任务页面点**新建任务**。给它起个名字（留空就用提示词命名），选时间，写提示词，再选智能体、模型和目录。**创建任务**会保存并打开它。

也可以让智能体帮你建：它可以像运行其他命令一样运行 `coffer task add`。

```bash
coffer task add --data '{"config": {"schedule": {"kind": "daily", "time": "02:00", "timezone": "Asia/Singapore"},
  "prompt": "Check last night'"'"'s build", "agent": "codex", "cwd": "~/work/site"}}'
coffer task list
```

## 一次运行是什么样的 {#what-a-run-looks-like}

到点时，智能体在一个新会话里收到提示词。晚了的运行或手动启动的运行会附一句简短说明，让智能体判断这件事是否还值得做。Coffer 不会往任何地方发消息：从运行记录里打开那次运行就能看到回复。如果需要智能体通知你，在提示词里写上；它可以用 `coffer__channel_notify` 通过你的渠道给你发消息。

上一次还没跑完时又到点的运行会被跳过并记录。失败的运行不会重试，因为一轮对话可能已经做了一些事；重复任务连续失败三次会被暂停。一次性任务运行后会被关闭。

## Mac 休眠时 {#when-the-mac-was-asleep}

Mac 休眠或 Coffer 没在运行时什么都不会运行；Coffer 不会唤醒 Mac。恢复后：

- 最近一次错过的运行会补跑一次，并说明它原本应在什么时候运行；
- 一次性任务最多可以晚它等待时间的一半（至少 15 分钟，最多 2 小时）；
- 重复任务错过的运行在当天结束前仍可补跑；
- 更早的都会被跳过并记在运行记录里。

关掉任务的**补跑**，就会跳过所有错过的运行。

## 页面 {#the-page}

列表显示所有任务，最近要运行的在前；每行写着下次运行时间，或者它已暂停、正在失败。

打开一个任务可以看到顶部（**立即运行**、**暂停**或**恢复**、**编辑**，以及 **⋯ › 删除**）、它做什么，以及**运行记录**：每次运行，最新的在前，写着结果——**完成**、**跳过**、**失败**、**已停止**——以及原因。每次运行都以链接给出它的会话：点进去会跳到**会话**页面并选中它，同时在终端里打开，你可以看这次运行做了什么并接着聊。运行记录默认保留 90 天；在设置 › 数据里修改。
