# 简介

Coffer 是一个本地优先 (local-first) 的 AI agent 保险库，让你在一个地方统一管理所有 MCP 服务器。

Coffer 是一个守护进程 (daemon) + CLI，它把上游 (upstream) MCP 服务器聚合起来，再通过一个统一、带命名空间的接口重新暴露给各类 MCP 客户端（Claude Code、Codex）。配置一次，所有客户端看到的工具完全一致。所有状态都保存在你自己的机器上 —— 没有云账号，没有厂商锁定。

## 为什么选择 Coffer？

在 Coffer 出现之前，每增加一个 MCP 服务器，就意味着要分别更新所有 AI 客户端（Claude Code、Codex 及未来的新成员）的配置。每个客户端各维护一份列表，同一个服务器需要重复注册，一处修改也不会自动同步到其他地方。

Coffer 的解决方案是：成为你 MCP 服务器的唯一事实来源。只需在 Coffer 注册一次，通过 shim 接入的所有客户端就能自动看到完全相同的工具集。

### 本地优先的设计

所有用户状态都驻留在你的机器上。云服务仅作为 LLM 与工具的提供方——它们绝不充当任何仓库状态的事实记录方。HTTP API 仅绑定到 `127.0.0.1`。你的配置、凭据和审计历史只属于你自己。
